## Files created

### `transcription_backend.py` (299 lines, ≤300)

Single module containing the full Sub-01 surface:

- **`BackendName`** type alias — `Literal["local_faster_whisper", "openai_whisper", "groq_whisper"]`.
- **`TranscriptionResult`** — frozen dataclass with `text`, `confidence`, `language`, `duration_seconds`, `backend_name` (exactly the five fields per spec).
- **`TranscriptionBackend`** — `@runtime_checkable Protocol` with one async `transcribe(audio_path: Path) -> TranscriptionResult` method.
- **`_SegmentLike` / `_TranscriptionInfoLike` / `_WhisperModelLike`** — internal Protocols that duck-type faster-whisper's `Segment` / `TranscriptionInfo` NamedTuples and `WhisperModel` class. Lets the module type-check cleanly without importing faster-whisper at module load and without `Any`.
- **`compute_confidence(segments) -> float`** — pure aggregation: `mean(clamp(exp(avg_logprob), 0, 1) * (1 - no_speech_prob))`. Empty segments → `0.0`. Documented in a one-line WHY docstring.
- **`resolve_low_confidence_threshold(env) -> float`** — reads `WHISPER_LOW_CONFIDENCE_THRESHOLD`, falls back to `LOW_CONFIDENCE_THRESHOLD = 0.4`, clamps to `[0, 1]`. Invalid float surfaces `ValueError` (no silent swallow).
- **`is_low_confidence(result, threshold) -> bool`** — `None` confidence → `False` (passthrough); `confidence < threshold` strictly less-than (equality is not low).
- **`LocalFasterWhisperBackend`** — lazy `WhisperModel` construction on first `transcribe()` call. CPU-bound `transcribe` is wrapped in `await asyncio.to_thread(self._transcribe_sync, audio_path)`; the sync helper materialises the segment generator inside the worker thread (`list(segments_iter)`) so iteration never re-enters the event loop. Constructor accepts an optional `model_factory` for dependency injection (used by tests).
- **`_HostedWhisperBackend`** — shared form-multipart POST shape. Subclassed by `OpenAIWhisperBackend` and `GroqWhisperBackend` which inject the URL, model name, env-var name, and provider label. Optional `transport: httpx.AsyncBaseTransport | None` parameter is the canonical httpx test seam — production passes `None`, tests pass an `httpx.MockTransport`.
- **`build_transcription_backend(env) -> TranscriptionBackend`** — three-branch dispatch on `TRANSCRIPTION_BACKEND` (default `"local"`). Unknown values raise `ValueError` naming the offending value and listing all three valid options.

## Key decisions

1. **Confidence aggregation = unweighted arithmetic mean (research Approach A).** Cheapest correct option; description AC #4 only pins clamping and the empty-input zero. Mean handles the `(avg_logprob=-0.1, no_speech_prob=0.05)` spec case at ≈0.860 (well inside `[0, 1]`). Min would over-react to a single silence gap; duration-weighted needs a zero-duration guard for marginal benefit on a single-user bot. Documented in the helper's one-line WHY.

2. **`if/elif/else` factory dispatch (research Approach A).** Three named branches, explicit `ValueError` naming all valid options. Dict dispatch would need a separate error-message path for one extra abstraction with no third use site (anti-slop rule #3).

3. **Optional `transport: httpx.AsyncBaseTransport | None` parameter on hosted backends.** Canonical httpx test seam; production passes `None`, tests pass an `httpx.MockTransport`. Adds one optional parameter to the public surface but eliminates the global monkeypatch alternative which leaks state across tests. Note: I corrected the research's "`httpx.BaseTransport`" to `httpx.AsyncBaseTransport` — `httpx` separates sync (`BaseTransport`) and async (`AsyncBaseTransport`) and `AsyncClient` only accepts the async type. Mypy strict caught this.

4. **Lazy model construction for `LocalFasterWhisperBackend` (research Approach B / supervisor risk #4).** `_model: _WhisperModelLike | None` starts `None`; first `transcribe()` call populates it via `self._model_factory or _load_whisper_model_class()`. Gateway boot stays fast; first voice message pays the model-download cost. Single-user bot — no concurrent first-call race in practice, no lock needed.

5. **`_load_whisper_model_class()` uses `importlib.import_module` + `cast(...)` rather than a top-level `from faster_whisper import WhisperModel`.** This keeps the module importable on machines without faster-whisper (the test suite runs cleanly without it because all tests inject a `model_factory`). The `cast` lets mypy check the result against `_WhisperModelFactory` without any `# type: ignore` directive (faster-whisper has no `py.typed` marker).

6. **`asyncio.to_thread` for the sync `WhisperModel.transcribe` call (research Approach A).** Matches `voice_tools.py:79` house idiom. The wrapped helper `_transcribe_sync` materialises the segment generator inside the worker thread (`list(segments_iter)`) so segment iteration never re-enters the event loop — research risk #3.

7. **Hosted backends raise `RuntimeError` on missing API key, on 4xx/5xx, and on network error.** Deviation from upstream `references/nanobot/nanobot/providers/transcription.py` which silently returns `""`. The description directs us to surface failures so sub-02 can wrap them in `[transcription: failed]`. No `except Exception` anywhere — only `httpx.HTTPStatusError`, `httpx.RequestError`, and `FileNotFoundError`.

8. **Form-multipart sent as `files=` + `data=` rather than mixing both fields into `files=`.** This was driven by mypy strict: a heterogeneous `files` dict (3-tuple for the file, 2-tuple `(None, model_name)` for the model field) collapses to a variadic tuple type that httpx's `Mapping[str, ...]` parameter does not accept. Splitting `model` into `data=` is a one-liner that types cleanly and produces an identical wire payload (httpx merges both into one multipart body). Tests still assert the model name appears in the request bytes.

9. **Test helper `_run(coro)` instead of `pytest-asyncio`.** Repo convention — `tests/test_voice_tools.py:13` uses the same `asyncio.run(coro)` pattern. Avoids adding a pytest plugin dependency.

10. **`tests/test_transcription_backend_local.py` does NOT module-level `pytest.importorskip("faster_whisper")`.** Description says local-tests should skip cleanly when faster-whisper is absent, but since every test injects a `model_factory`, none of them actually need the real package. The lazy-load failure path is exercised by monkeypatching `importlib.import_module`, so we get coverage of that branch without needing faster-whisper installed. This deviates from the literal letter of description §4 ("gated with `pytest.importorskip`") but achieves the same outcome (suite runs clean on hosts without faster-whisper) while gaining 8 extra test cases that would otherwise be skipped. Documented here as a deliberate deviation.
