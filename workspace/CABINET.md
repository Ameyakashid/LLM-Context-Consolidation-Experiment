# The Cabinet — Fire Tablet Display Setup

This file is for you, the human. "The Cabinet" is the wall display that runs
on your Fire tablet. It replaced MagicMirror² — there is **no Node/npm
anymore**. A tiny Python server (built into the bot) serves a static page on
your LAN; the bot writes small feed files that the page polls.

## TL;DR

1. Put `CABINET_ENABLED=true` and `CABINET_AUTOSTART_ENABLED=true` in your `.env`.
2. (Optional) Point `CABINET_WALLPAPER_DIR` at a folder of images for the screensaver.
3. Run `python setup_workspace.py` (no Node needed — it just checks the `cabinet/` folder is present).
4. Start the bot: `python start.py`. The Cabinet server comes up on port 8080.
5. On the Fire tablet, open Silk to `http://<your-pc-lan-ip>:8080/`.

That's it. The display has four modes (rail buttons or keys `d` `n` `w` `f`):
**The Cabinet** (dashboard), **The Gazette** (news), **Wallpaper**
(screensaver), and **The Codex** (flashcards).

## What it shows

- **Dashboard** — three auto-rotating pages: *Obligations* (your tasks, with a
  rolling hero headline), *Inner Weather* (cognitive state + buffers), and
  *The Hours* (check-in schedule). Plus a drifting strip of your real inner
  voices (Volition / Empathy / Logic). It refreshes about every 30 seconds.
- **Overlays** — when your cognitive state shifts, a buffer runs low, or a
  check-in is missed, a full-screen overlay appears within a few seconds.
- **The Gazette** — real news headlines (pulled on the PC, never the tablet).
- **Wallpaper** — slowly cross-fades through images from your local folder.
- **The Codex** — study flashcards; tap the ↻ button to draw a fresh set.

## How it's driven

Everything is **read-only from the tablet's perspective** — the tablet only
*reads* files the bot writes; it never reaches the internet.

- The bot writes `cabinet/feeds/*.md` and `cabinet/feeds/*.json` atomically on
  a ~30s loop (tasks/state/schedule/voices), and an alert queue
  (`alerts.json`) the page polls every ~5s.
- News (`news.md`), the flashcard pool (`flashcards.json`), and the wallpaper
  `manifest.json` are regenerated by the bot on slower cadences.
- The inner voices are your real Disco-engine lines: captured when they fire
  in chat, topped up in the background so the strip is never empty.

## Env vars

| Var | Default | What it does |
|---|---|---|
| `CABINET_ENABLED` | `false` | Master switch (falls back to `MAGICMIRROR_ENABLED`). |
| `CABINET_AUTOSTART_ENABLED` | `false` | `start.py` runs the static server in-process. |
| `CABINET_HOST` | `0.0.0.0` | Bind address (all LAN interfaces). |
| `CABINET_PORT` | `8080` | Port the tablet connects to. |
| `CABINET_IP_WHITELIST_JSON` | loopback + RFC1918 | Who may connect. |
| `CABINET_WALLPAPER_DIR` | `cabinet/wallpapers` | Local image folder for the screensaver. |
| `CABINET_NEWS_QUERY` / `_MAX` / `_S` | `world news` / 8 / 3600 | News topic, count, refresh seconds. |
| `CABINET_RENDER_S` | `30` | Feed re-render cadence. |
| `CABINET_VOICE_TOPUP_S` | `5400` | Inner-voice buffer top-up cadence. |
| `CABINET_FLASHCARDS_S` | `21600` | Flashcard pool regeneration cadence. |
| `CABINET_WALLPAPER_S` | `60` | How often the wallpaper folder is rescanned. |

## When it breaks

- **Tablet can't reach it.** Ping `http://<pc-lan-ip>:8080/` from the Fire's
  browser. If it times out: the bot isn't running, the firewall is blocking
  inbound 8080, or the tablet's IP isn't in `CABINET_IP_WHITELIST_JSON`.
- **Screen looks stale.** Feeds refresh every ~30s; confirm `start.py` is
  running and `CABINET_ENABLED=true`.
- **No news / generic voices / no flashcards.** Those depend on the LLM /
  network on the PC; on failure the display keeps its last good content or a
  built-in fallback, so it's never blank.
- **Wallpaper empty.** Drop images into `CABINET_WALLPAPER_DIR`; within a
  minute they appear (a `manifest.json` is regenerated automatically).

## Turning it off

Set `CABINET_ENABLED=false` (and `CABINET_AUTOSTART_ENABLED=false`) and
restart. The flag-off path starts no server and writes no feeds.
