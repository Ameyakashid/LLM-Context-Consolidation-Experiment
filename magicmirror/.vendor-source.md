## Install caveat — `--ignore-scripts`

Upstream `package.json` declares a `postinstall` that runs
`git clean -df fonts vendor modules/default`. This fails in a non-git tree
(the vendor drop ships without `.git/`). `setup_workspace.py` invokes
`npm install --ignore-scripts` on this directory to defuse the postinstall
without editing the vendored `package.json` (which would break
byte-identity). Module-level installs (under `modules/MMM-*/`) do not
carry destructive postinstalls, so they run without `--ignore-scripts`.
